# 复现协议

本页描述当前 Qwen 三卡确定性全量包。状态日期：2026-10-18。机器可读配置见 [config.json](../offline_tta/tlm_tent_full_3gpu_det_bundle/config.json)，数据哈希见 [selected_datasets.json](../offline_tta/tlm_tent_full_3gpu_det_bundle/selected_datasets.json)。

## 固定来源与数据

- 上游：[Fhujinwu/TLM](https://github.com/Fhujinwu/TLM)，固定提交 `496c9ed97d0fb8bc4854ed2479259e7e9e70a790`。
- 模型：Qwen2.5-7B-Instruct，基础参数 FP16 冻结；当前记录依靠已部署模型和预检基础权重摘要，尚需补充模型上游 revision，不能声称模型 revision 已锁定。
- GeoSignal、Dolly、GSM8K 每套 5000 条，均来自该 TLM 提交。保持文件哈希、原始索引和顺序，不替换同名数据来源。
- GeoSignal / Dolly 主指标 ROUGE-Lsum；GSM8K 使用上游答案提取器和 Exact Match。评分口径变动必须单独命名并全方法统一。

## 适应与评测流程

每个数据集新进程、同一基础模型和 seed=42 新建 LoRA / Adam。先做 5000 条冻结 Source 预测，再对全部 5000 条无标签输入依次更新，最后对 5000 条统一生成并评分。该流程是 offline，不与逐条先更新后评分的 online 结果混表。

参考答案只在评分阶段使用，不进入损失、筛选或超参数选择；适应函数仅接收 instruction/input。每组模型与优化器独立，不能继承上一数据集的更新。

| 设置 | 当前全量值 |
|---|---|
| 设备 | 三张 RTX 2080 Ti，物理卡号在运行时协调并记录 |
| 模板 / 解码 | TLM qwen，greedy，batch=1，seed=42 |
| 输入 / 适应生成 / 评测生成上限 | 4096 / 80 / 512 token |
| 输入截断 | 固定尾部截断，GeoSignal 2 条、Dolly 1 条；Source 与 Tent 相同规则 |
| 参数 | q_proj、v_proj 的 LoRA；rank=8、alpha=16、dropout=0 |
| 可训练参数 | 2,523,136 个 FP32 参数；基础权重 FP16 冻结 |
| 损失 | 有效自生成位置的全词表预测熵，FP32、自然对数、位置平均 |
| 掩码 | 排除提示、PAD、停止符及后续位置；考虑因果位移 |
| 优化器 | Adam，betas=(0.9,0.999)，eps=1e-8，weight_decay=0 |
| 学习率 | GeoSignal / Dolly：5e-5；GSM8K：1e-6 |
| 检查点 | 每 25 条适应保存 adapter、Adam、随机状态与游标 |
| 确定性 | 严格 deterministic algorithms，warn_only=False，cuBLAS workspace `:4096:8` |

80 token 是适应前缀预算，512 token 是评测预算。旧 16 条调试实验输入上限为 1024；其指标不能作为当前全量 Source 的替代。

## 与原方法的关系

当前方法名称为 `Tent-text-LoRA offline full engineering reproduction`。LoRA 参数集合和当前学习率属于记录清楚的文本工程设置，尚未核实作者 Tent 基线全部细节。三卡分摊、长输入内存优化、严格确定性与断点恢复属于工程实现与验收措施，不构成方法效果证据。

纯文本生成复用 TLM 模型加载器和提示模板，直接调用 `model.generate`，避开已有旧聊天包装接口与多模态插件参数不匹配问题。该入口差异需保留在报告中。

EATA / SAR / DeYO 开始前分别写明：官方来源、原损失与筛选模块、文本适配假设、参数集合、阈值、Fisher/扰动/重置等适用部分、标签访问和验收。Llama 需独立模板/设备/参数验证，不能把 Qwen 配置直接改模型名后视为复现。

## 通过条件

预检要求真实梯度与参数变化、基础权重不变、长输入可运行、adapter / Adam / RNG 恢复和继续一步逐元素一致。正式运行要求完整 manifest、全部指定样本、逐条预测、comparison 与 metrics、异常计数和开销。两者分开验收，分数下降也如实报告。
