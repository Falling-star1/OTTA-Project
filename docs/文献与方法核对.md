# 文献与方法核对

当前实验以 [TLM 官方仓库](https://github.com/Fhujinwu/TLM)的固定提交 `496c9ed97d0fb8bc4854ed2479259e7e9e70a790` 为来源。论文入口：[Test-Time Learning for Large Language Models](https://arxiv.org/abs/2505.20633)。

| 方法 | 当前要核对的内容 | 实现状态 |
|---|---|---|
| Tent | 作者参数集合与完整超参数；熵位置与掩码；文本 LoRA 差异 | 当前工程适配通过小样本与长输入预检，正式结果待登记 |
| EATA | 可靠性、冗余筛选、Fisher 与正则；文本版本定义 | 未实现 |
| SAR | 可靠性与鲁棒优化模块；文本损失、恢复规则与实现对应 | 未实现 |
| DeYO | 原扰动/筛选思想如何适用于文本，保留项和改动项 | 未实现 |
| OPUS | 核定老师指定的论文版本、官方实现、proxy pool 定义 | 待核定，不凭同名项目认定来源 |

新方法先提交来源、公式/代码对应表、参数与标签访问规则，再实现与验收。历史阅读材料位于[原主线文献资料](../archive/github-main-20261018/文献资料/论文阅读总表.md)，保留当时标题、计划和笔记，不当作本轮已核实实现规格。

TTT / MEMO 学习资料和额外阅读文件保留在原本地研究目录，本次不把外部论文全文、大型资源或无关源码一并上传。需要团队共享时，先整理为有来源的阅读笔记与链接，再通过独立 PR 收录。
