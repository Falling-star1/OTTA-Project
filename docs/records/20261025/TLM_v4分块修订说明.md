# TLM v4分块修订

这次直接修改训练代码，候选包见[v4运行说明](../../../offline_tta/tlm_offline_v4_bundle/README.md)。旧v3及诊断记录保留，不覆盖原运行。

## 修了什么

原分块路径最后可能只投影1个位置，与前面128-token块采用不同矩阵形状。v4在head内部用零hidden和ignore标签补齐末块，虚拟位置不进入损失、分母或真实输入。checkpoint现在返回逐token CE，拼接后一次FP32求和，保持完整路径的归约顺序。

这两处已由先失败、后通过的回归检查覆盖。浮点归约压力用例中，旧分块和为100000360，完整和为100000304；新实现与完整和一致。该用例用于证明旧求和顺序能产生数值差异，不代表实际Dolly输入有这么大的损失，也不证明真实GPU残差已全部消除。

正式预检也补齐实际GradScaler反传与还原，保留原逐元素和1%相对L2要求。只在非有限时联合回退scale，不按误差选scale。失败会保存全部参数统计，缺失梯度立即失败。chunk_size绑定到预检身份，阻止不同块大小混用收据。

## 与TLM原文的关系

目标函数、筛选加权流程核对固定官方实现，初始化使用论文Gaussian A、零B。TLM公式、阈值、学习率和真实输入目标不因本次修订改变。分块是显存限制下的自有工程实现，必须与完整计算对齐，不能直接称为原文代码。

当前仍使用2080 Ti FP16和Qwen3B，另有答案独立截断调整。因此应称按TLM方法进行的3B/FP16复现实验；本次修订不消除硬件、模型规模和预处理条件差异。

67项CPU检查通过，包含原60项、7项新增回归；独立复核提出的失败诊断缺口已补齐。服务器Torch2.5.1与本地Torch2.14不同，v4真实GPU完整预检尚未执行。此前v3真实缩放比较仍为MISMATCH，不能替代v4验收。
