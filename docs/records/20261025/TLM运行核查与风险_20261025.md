# TLM运行核查与风险说明

核查时间：2026-10-25，北京时间16:14–16:23。读取全部适应记录、最终权重、检查点和已生成预测，没有重新训练或修改参数。按用户要求，于16:19暂停两组Dolly评测，其他四组继续。

## 结论

训练目标、样本筛选和权重与固定官方代码一致，输入与答案已分离。但两组Dolly出现了输出退化，不能把“程序能运行”当作“方法复现成功”。

本轮是源码对齐的FP16工程复现，不能称为论文条件下的严格数值复现。尤其要区分论文的Gaussian初始化与固定源码采用的PEFT默认初始化。

## 已经出现的问题

下表为16:22核对的同索引预测前缀，不是5000条最终成绩。Source与TLM使用完全相同的前n条问题。

| 实验 | 条数 | Source ROUGE-Lsum | TLM ROUGE-Lsum | 问题 |
|---|---:|---:|---:|---|
| Llama＋Dolly | 267 | 32.42% | 26.84% | 35条高重复，约13.1%；Source相同前缀没有同定义高重复 |
| Qwen＋Dolly | 179 | 27.75% | 15.89% | 84条空回答，约46.9%；Source相同前缀无空回答 |

重复的诊断规则：对解码文本按单词和标点切分，统计连续四元组；`1－不同四元组数/全部四元组数`达到0.5计为高重复。两种输出使用相同规则。人工核对发现“Pesach”“grace”等词循环生成到512-token上限。

Source未保存生成token IDs，不能把缺失的token级重复统计当作0；这里用双方都有的解码文本比较。

Qwen的84条空回答均只生成token `151645`，与该模型登记的结束符一致，是模型直接结束回答，不是评分器误删文本。空回答在前后半段均存在。

两组最终权重已经固定，继续评测只会补齐统计，不会让模型继续学习。退化现象已确认，具体成因尚未由对照实验确定，不能直接归因于FP16、初始化或某个超参数。

## 与原文和固定源码的关系

| 项目 | 本轮设置 | 对齐程度 |
|---|---|---|
| offline | 全部问题先适应，再统一评测 | 与论文一致 |
| 筛选与权重 | 基座评分，CE阈值3，lambda=0.1 | 与固定代码一致，对应困惑度阈值e³ |
| 目标 | 加权输入CE，等价替代官方one-hot KL | 跟随代码；论文用困惑度写目标，不能把文字公式和代码不加区分地视为相同目标 |
| LoRA模块 | q/v、rank8 | 与论文对应 |
| 初始化 | `init_lora_weights=True`，PEFT 0.12.0为Kaiming uniform A、零B | 对应固定源码默认路径；论文为Gaussian A、零B，有明确差异 |
| 模型 | Llama-3.2-3B、Qwen2.5-3B | Llama在论文中；论文Qwen为7B，本轮Qwen3B是扩展 |
| 精度 | FP16、2080 Ti | 官方示例BF16、论文A800 80GB，数值条件不同 |
| 优化器 | AdamW、weight decay=0 | 跟随框架默认值；论文写Adam，不能把名称差异当作退化的已证实原因 |
| 配方 | batch1、一轮、三类任务学习率、cosine和warmup | 学习率等对应论文，调度依据固定示例 |
| 预处理 | 答案独立，保留完整模板，裁剪用户内容 | 修正官方处理器中答案长度影响截断的路径，属于披露的工程改动 |
| 指标 | ROUGE-Lsum、GSM8K Exact Match | 对应论文主指标 |
| 范围 | 三个数据集，各5000条 | 只覆盖AdaptEval部分任务 |

## 后续排查与风险

1. 保留当前Dolly运行，不改最短生成长度、重复惩罚或停止符来掩盖空答与循环。
2. 在固定输入上比较原模型、早期LoRA里程碑和最终LoRA，定位退化从哪一步开始，检查第一token结束符倾向及回答格式。该诊断只定位问题，不按测试分数挑选最佳检查点替换本轮最终模型。
3. 从同一初始状态，对照原始官方短序列实现与分块实现的损失、梯度和更新轨迹。CPU等价测试已通过，真实FP16路径仍需独立核对。
4. 若补论文设置对照，Gaussian初始化单独登记新运行，不在原目录静默替换；BF16对照需要支持该类型的硬件。
5. 其他四组继续，但当前只有顺序前缀，Qwen部分组样本尤其少。不能据前缀分数声称达到论文结果或显著提高；单种子也不足以判断稳定性。

后续持续核对空答率、重复率、512-token触顶率、同索引Source分差，以及检查点和配置身份。训练损失下降不能替代输出质量检查。当前两组Dolly暂停，恢复或补跑需要另行登记。

现有启动器只保证流程和数值门禁，尚无正式训练后的自动输出质量拦截。本次通过人工审查发现问题并暂停。后续每组应在正式评测前100条时检查上述信号，不能等5000条全部生成后才看异常，也不能把这条检查约定描述为已经部署的自动监控。
