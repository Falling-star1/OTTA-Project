# Dolly 复现排查与修复范围

用户要求解决复现问题，沿用此前批准的“保留原实验、独立做模板对照”路线。主实验不按分数调参，旧结果不覆盖。

先以冻结 v6 在同一 5000 条数据、同一采样顺序、同一 5000 步调度下重放前 200 步，并与原记录及 step-100 adapter 对账。对照只改变损失位置，保持实际输入、学习率、底模、Gaussian 初始权重和评测问题相同。两个因素分别是聊天角色格式和 Dolly 数据自带的 Instruction/Response 格式，得到 all / role_masked / wrapper_masked / both_masked 四组。底模 CE 与筛选权重始终按原完整输入计算，避免掩码同时改变选样。

诊断使用独立结果目录和空闲 GPU。记录全部目标位置、归一化分母、训练索引、真实成功步数、起始 token 的 argmax 与概率、只输出标题、重复和固定回答样本。屏蔽损失是机制对照，不冒充论文原方法；200 步未复现退化时不能宣称修复。

先查基线是否能重放。如果重放失败，停止后续因果解释，优先查实现差异。推理停止符按官方定义单独测试和记录，不在现有预测中途改变。新诊断和修复均须有可复核数据；无法证实的原因保持未确认。
