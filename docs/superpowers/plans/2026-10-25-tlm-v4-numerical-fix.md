# TLM v4分块数值修订

目标：直接修订训练损失的分块路径，不调整Gaussian、阈值、学习率或梯度容差。用户在看到未通过的真实缩放与16步报告后明确要求修复。

已有证据：完整和单块路径相同；128-token多块开始出现差异；真实缩放显著降低误差但逐元素门禁仍失败；关闭投影checkpoint未改善统计。尾块矩阵形状和FP32归约顺序是当前局部修订对象，真实GPU通过前不宣称根因完全解决。

- [x] 从冻结v3复制独立v4包，不修改旧运行。
- [x] 先补末块投影形状、全token求和顺序、虚拟位置无损失/梯度的失败测试。
- [x] 末块补零hidden和ignore标签至正常tile形状，保留全部真实预测位置。
- [x] checkpoint返回逐token损失；拼接后按完整路径一次FP32求和，不保留整段词表logits。
- [x] 正式预检使用实际GradScaler反传和还原，按非有限结果联合backoff，保持原容差，并在失败时保存全部参数统计。
- [x] 预检身份新增chunk_size，阻止不同块大小混用收据。
- [x] CPU回归与独立复核后发布候选，提供两组Dolly的v4完整预检命令；通过前不启动全量。
