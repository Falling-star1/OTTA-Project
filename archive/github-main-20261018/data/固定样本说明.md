# Smoke 固定样本说明

## 用途

`smoke_32.jsonl` 是 Sprint 0 中 No Adaptation、Random、High-PPL 和 OTTA v0 共用的固定测试流。所有方法必须按文件中的既定顺序运行；不得在运行时重新随机抽样。

## 来源与生成规则

- 数据集：`allenai/ai2_arc`
- 配置：`ARC-Challenge`
- split：`validation`（299 条）
- 抽样数量：32
- 抽样 seed：42
- 抽样方法：对源数据行索引执行 `random.Random(42).sample(...)`，再按原验证集顺序排列入流。

## 文件

- `smoke_32.jsonl`：标准样本；仅 evaluator 可读取每条记录中的 `answer`。
- `smoke_32_ids.txt`：一行一个 `sample_id`，用于各成员核对样本顺序。
- `smoke_32.jsonl` 的 SHA-256：`3C152C99119C359C66F32AB5A7AB30BEC11C006D2DB85ABC802CA47F48139F20`

## 复现与校验

```powershell
$projectPython = '.\.venv\Scripts\python.exe'
& $projectPython -m src.data.prepare_smoke_data --output data/smoke_32.jsonl --ids-output data/smoke_32_ids.txt --count 32 --seed 42
& $projectPython -m src.data.prepare_smoke_data --check --output data/smoke_32.jsonl --count 32
& $projectPython -m pytest tests/test_prepare_smoke_data.py -q
```

生成命令会覆盖本文件与 ID 清单；只有在全组同意更换固定测试流时才可执行。
