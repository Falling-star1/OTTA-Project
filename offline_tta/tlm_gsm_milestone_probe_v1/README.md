# GSM8K 已保存权重检查

读取 Llama GSM8K 已完成运行的底模、1000 / 2500 / 5000步 adapter，不创建训练器或优化器。先在最终权重逐 token 重放第1与100条已保存回答，确认推理一致后才比较检查点。

所有阶段使用固定的前20条加随机80条问题。分别记录回答起点、强制提供完整 `Let's think step by step.` 前缀后的停止符概率和 argmax 次数；这些是两个不同的统计量。每个阶段另生成4条相同问题，仅检查行为，不作为全量成绩或检查点选择依据。

脚本不改提示、不增加生成长度、不修改答案提取器。只输出一句“Let's think step by step.”单独标记，和空字符串分开。参考答案仅在生成之后评分使用。

这项检查用于确认退化何时出现，不把概率相关性称为因果证明。结果写入全新目录，原权重、答案和分数均保留。
