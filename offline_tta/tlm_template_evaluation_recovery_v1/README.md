# 保留实际 AMP 差异的对照评测

冻结的1000步对照要求所有逐样本学习率都与原组完全相同。损失掩码可能改变梯度幅度、裁剪和FP16溢出，从而改变跳步时机，因此部分训练完成的对照被这个检查拒绝。原拒绝记录保留。

本入口不继续训练，也不把 `learning_rates_exact=False` 改成 True。它核验完整检查点哈希、原采样顺序、底模CE与权重、同一优化器和cosine定义，再用保存的真实Adam步数和scheduler状态逐条解释学习率轨迹。只能由该固定调度下的真实跳步解释的记录才允许评测，任意调参或无法解释的差异仍报错。

评测先加载正常基线权重并重放两条已保存回答，再加载被拒绝对照的实际权重。新结果写入独立目录，原失败、分数和主实验不改。

结果必须同时展示实际成功/跳步数和学习率差异。它可以说明损失位置干预的整体效果，不能单独证明纯语义效应与数值优化效应各占多少。
