# 推理协议与无实质回答检查

`official_stop_ids()` 按固定官方 workflow 使用 tokenizer EOS 加 additional_special_tokens_ids，去重后用于新建生成。不能只凭模型 config 中的 EOS 列表或模板停止词推断官方策略。

`audit.py` 在 CPU 上检查原运行完整预测前缀，先验证固定生成代码、tokenizer、索引及 token 解码文本一致，再按最早官方停止符解码已保存的贪心 token。结果写到全新目录，不覆盖预测，不改变分数或伪造训练修复。贪心单样本生成在更早停止符前的 token 不依赖后续生成，因此这项检查不需要重训。

标题空壳与空字符串分别统计：只输出一次或多次 `### Response:` 都不是实质回答。它们仍原样参与主实验评分。

Source 没有保存生成 token ID，不能对其做同等检查，因此不能用这份 TLM 单侧审计宣称已完成严格官方解码的配对比较。若官方停止符确实改变输出，另建完整配对评测；旧 Source/TLM 结果保留为原协议记录。

该包修正已确认的协议和诊断遗漏，不声称停止符差异就是 Dolly 退化原因。
