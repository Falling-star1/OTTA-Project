# GSM8K 开场白与结束符的损失对照

原输入均包含 `### Response: Let's think step by step.`，随后是用户轮次结束符。这里固定论文学习率1e-6、Gaussian初始权重、原5000条采样器与5000步调度，分别屏蔽开场白、其后用户EOT、两者的损失。输入不改，底模筛选与权重不改，保留目标仍用原完整目标数归一化。仅在2500步通过回调停止。

基线直接读取原来保存的2500步权重，不把它描述成独立重训。开始前使用已核验的Accelerate推理包装精确重放原最终权重的两条预测，释放该模型后重新创建Gaussian初始模型并逐张量确认初始权重一致，再交给Trainer准备，避免重复包装。训练后要求采样、学习率和底模CE与原前2500步一致，才比较控制组和原2500步基线。

固定100条问题分别记录正常回答起点和强制开场白后的结束符概率、argmax；8条固定生成只作行为检查，不替代全量EM或作为挑选最高分检查点的依据。旧分数与回答不修改。

该实验检查“输入中的开场白→用户EOT”这一训练信号是否促进回答过早停止。屏蔽目标属于机制对照，不直接改名为论文原方法；不能据小样本宣称已达到90.96%。
