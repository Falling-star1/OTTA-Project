# 原版 TLM 与固定官方实现的直接对照

本目录只新增审计和短步数诊断。正式结果采用 v6 原版六组完整结果；v7 与屏蔽目标的实验仅作为诊断材料保留。

官方提交：`496c9ed97d0fb8bc4854ed2479259e7e9e70a790`。

`audit_cpu.py` 调用官方 `SelfSupervisedDatasetProcessor` 比较六组各 5000 条输入，并直接调用官方 CE/KL 方法比较随机 logits 的损失与梯度。审计可读取原始参考答案，以复现官方参考长度参与截断的行为；不产生训练数据或更新权重。

`probe.py` 在单独的输出目录内对 GSM8K 做两条真实 Trainer 路径，各访问前 8 个样本：官方 `CustomSeq2SeqTrainer` 的原始损失实现，以及冻结的 v6 `TLMTrainer`。训练输入只有问题和上下文，不读取参考答案。两边使用同一个 Gaussian 初值、完整 5000 条数据集、batch 1、lr 1e-6、cosine、warmup 0.1、FP16，通过回调在第 8 步停止。保持完整输入，不缩短序列，不用 max_steps 改变调度。

比较项包含逐步索引、底模 CE、筛选、权重、损失、裁剪后梯度、GradScaler、AdamW 状态和相对初值的 adapter 更新；同时比对正式运行最初 8 条历史记录。脚本以记录差异为目的，`COMPLETE` 代表诊断执行完毕，不代表所有数值相同。

边界：这不是官方默认初始化对照，也不是 BF16/A800 实测，更不能证明 5000 步训练轨迹或论文分数等价。公开正常 LoRA 分支省略初始化参数；当前 PEFT 默认与论文 Gaussian 描述存在区别，需在报告里保留。所有原版结果和修订实验均不覆盖。
