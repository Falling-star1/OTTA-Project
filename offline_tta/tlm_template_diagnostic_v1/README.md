# Dolly 格式学习排查

这是独立诊断，不替换论文原方法或现有全量结果。

四组保持同一 Gaussian 初始权重、输入 token、5000 条采样器、5000 步调度、500 步预热和论文学习率，只改变当前输入损失中哪些位置保留：全部、屏蔽角色格式、屏蔽数据自带格式、同时屏蔽两者。保留项仍除以原完整目标数，底模 CE 与筛选权重不变。第 200 步通过回调停止；不把数据和调度直接缩为 200 条。

先重放 all 基线。必须与原采样顺序、学习率、前 200 步损失及 step-100 adapter 对上，才允许启动屏蔽组。屏蔽属于机制对照，不能改名为论文原文复现。

输入按实际 token offsets 分成 role / wrapper / body，并保存每个位置。基座和适应模型分别测前20条及固定随机80条的下一 token 排名与停止概率。概率平均值和 argmax 次数分别统计。另取8条未用于短训练的固定问题，使用原模板和 greedy512 生成，保存与配对 Source 的原文、分数及标题空壳、重复标记。8条分数仅作检查，不替代5000条全量成绩。

只输出 `### Response:` 也记为无实质内容，不与空字符串混淆。全量结果和原评分保持原样。

运行使用原有 GPU 锁，仅能选空闲单卡；导入冻结 v6，不修改其文件或原 run。启动前导出 `CUDA_VISIBLE_DEVICES` 与 `CUBLAS_WORKSPACE_CONFIG=:4096:8`，激活原有环境。运行失败写入新目录 `failure.json`，基线失败则停止解释后续因果关系。
