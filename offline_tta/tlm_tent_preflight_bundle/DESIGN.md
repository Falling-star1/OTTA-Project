日期：2026-10-18。

范围：只验证 Qwen2.5-7B-Instruct 上的一次无标签熵最小化更新；不运行全量实验，不宣称四种方法已经复现。

## 为什么先做这一步

Source 的 48 条小样本生成与评分已通过。512-token 设置下，GSM8K 为 12/16，三个数据集均无输入截断或空预测。
下一项风险是训练流程：能生成回答不代表多卡上能正确反向传播、只更新指定参数且不读取测试答案。

## 已知依据与实现空白

- TLM 附录 C.2 说明 Tent 使用模型生成的 80 个 token 的预测熵更新参数；主实验比较采用 offline 设置。
- 同一附录介绍 LoRA rank=8、作用于 q/v 投影，但没有在 Tent 段落单独明确其参数集合；不能把这当作已确认的作者 Tent 配置。
- 原版 Tent 官方实现更新 BatchNorm2d 的仿射参数。Qwen 使用 RMSNorm，原版配置不能原封不动使用。
- 当前固定的 TLM 源码提交尚未找到 Tent 基线实现；不能假装已有可直接执行的训练命令。

来源：[TLM §5.1、附录 C.2](https://arxiv.org/html/2505.20633v1#A3.SS2)、[Tent 官方实现](https://github.com/DequanWang/tent/blob/master/tent.py)。

## 两种可行方案

| 方案 | 优点 | 需要承认的差异 |
|---|---|---|
| A：生成熵 + q/v LoRA（推荐先做） | 与 TLM 已公开的低秩更新设置兼容；基础权重冻结；便于后续统一四种方法的可更新参数 | Tent 基线是否也使用此参数集合尚未得到作者代码证实；名称明确为 Tent-text-LoRA 工程适配 |
| B：生成熵 + RMSNorm 的缩放参数 | 更接近原版 Tent 只更新归一化参数的思路；训练参数更少 | RMSNorm 没有 BatchNorm 的批统计量及平移参数，仍是文本适配；也不是已确认的 TLM 作者配置 |

不采用全参数更新作为本次预检路线，避免额外引入显存和优化器状态成本。
本方案选择 A，只验证工程正确性。正式方法比较前需要保留参数适配说明，并在可能时查明作者实际基线配置。

## 熵目标与数据流

1. 加载未经修改的基础权重，在其上创建 LoRA。基础权重 requires_grad=False，优化器只接收 LoRA 参数。
2. 为预检样本构造不含参考答案的提示 x，在 no_grad 下 greedy 生成最多 80 个 token；生成 token ID 与计算图分离。
3. 在当前参数下重算 x 和生成前缀的前向传播，对每个有效生成位置得到全词表分布 p。
4. 计算 `H(p) = -sum_v p(v) * log(p(v))`，词表求和和熵使用 FP32；在有效生成位置取平均，单位为 nat，不除以 log(词表大小)。
5. 因果位移必须正确：提示长度 P 时，首个生成 token 对应 logit 位置 P-1；损失不覆盖提示位置。PAD 和模板停止符不参与损失；若没有有效生成 token 则明确失败。
6. 执行一次反向与 Adam 更新。所有梯度与参数必须有限；记录变化量及显存。
7. 使用同一条已分离的生成前缀重新计算熵，报告更新前后数值。单步熵下降不是通用保证，也不等于任务分数提高；不以挑选参考答案得分作为接受条件。
8. 本次不保存覆盖基础模型的文件，也不把预检 adapter 当作正式数据集实验起点。后续实验从原始模型及新初始化 LoRA 开始。

采用对固定生成前缀重算预测分布的方式进行微分；不是把模型生成答案当作有标签交叉熵训练，也不是最小化输入困惑度。

## 必须通过的检查

- 纯函数测试：熵公式与已知分布一致；提示位置、PAD/停止符不计入熵；首个生成 token 位移正确；空掩码和非有限值报错。
- 标签隔离测试：把输入记录的参考答案替换为明显不同的字符串，适应函数收到的输入及计算结果必须不受影响。适应函数接口不接受参考答案。
- 小模型训练测试：只启用指定 adapter，有限且非零梯度、一步参数变化、优化器及 adapter 重置后恢复初始状态。
- 真实 Qwen 预检：打印全部可训练参数名、参数总数和设备位置；基础权重无梯度，优化器没有基础参数；至少部分 LoRA 参数实际变化，更新前后均有限。
- 对全部基础参数以小块传回 CPU 计算更新前后摘要，验证基础权重不变；不在 GPU/CPU 中额外复制整个模型。
- LoRA 的 B 零初始化意味着第一步部分 A 梯度可为零；验收要求整体存在非零梯度和实际更新，不要求每个 LoRA 张量都变化。
- 两张设备均可正确参与前向/反向，无 CPU/disk 模型卸载；任何异常均非零退出。

全部通过才输出 `TENT_SINGLE_STEP=PASS`。该标记仅表示单步流程正确，不表示 Tent 性能提升或论文复现完成。
