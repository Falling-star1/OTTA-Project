# 1000 步模板对照调度

200 步基线已精确重放，但 Llama 仅 10% 探针以 `###` 起始，尚未重现全量后的约99%。因此延长到1000步后再解释机制，不能把短验证中的表面正常称作修复成功。

队列使用已经冻结的 `tlm_template_diagnostic_v1`，不修改训练实现。每个模型先完成 all 基线及精确重放，才允许同模型三组损失掩码对照。基线失败会阻止其后续对照，不自动重试或换参数。

只使用明确登记的 GPU 0、4、7，并检查空闲状态、继承原 GPU 锁。原实验的 GPU 1、2、3、5、6 和所有原输出目录保持原运行。每个任务使用新目录，完整命令、进程号、状态和实际结果均保留。

8条生成样本和100条起始 token 探针仅供定位；不是全量性能结论，也不把掩码版本改名成论文原文方法。
