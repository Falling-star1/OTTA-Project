此脚本保留另外五组全量，在 GPU 6 上重新完成 Dolly 完整预检、100 条训练和生成，全部通过后才从底模新建 Gaussian LoRA 跑该组全量。它复用冻结的 v6 训练代码与既有控制器检查函数，不修改数学实现、学习率、容差或旧回执。每阶段重新核对规范底模、代码、回执和输入身份。

新输出使用独立目录。旧运行根目录的 `recovery_qwen3b__dolly_5k.json` 记录替代路径；原控制器及其失败历史保留。查看恢复是否成功，应读取恢复根目录的 `status.json`，不能把原控制器的状态当成这组恢复结果。
