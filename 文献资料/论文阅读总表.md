## 6. 对本课题最重要的比较轴

| 方法 | 样本选择依据 | 优化器感知 | LLM适用性 | 在线 | 主要风险 |
|---|---|---:|---:|---:|---|
| Random | 随机 | 否 | 是 | 是 | 只适合作为下界 |
| Confidence / Verifier | 置信度或验证器 | 否 | 是 | 是 | 额外模型或确认偏误 |
| High-PPL / Entropy | 困惑度或熵 | 否 | 是 | 是 | 难样本可能是噪声 |
| EATA | 不确定性与冗余过滤 | 弱相关 | 主要为CV | 是 | 迁移到LLM需要改造 |
| OPUS | 优化器诱导效用 | 是 | 预训练场景 | 批量 | 原方法不直接适合TTA |
| OTTA v0 | AdamW预条件方向对齐 | 是 | 是 | 是 | 单样本梯度开销和方向锁定 |
