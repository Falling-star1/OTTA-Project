## 它解决的问题

TTA 领域论文快速增长，传统综述更多关注模型参数适应；这篇综述强调除了直接改模型之外，还可以在推理过程、归一化层、样本和提示等层面做测试时适应。

## 方法分类

综述给出的五类框架：

1. Model adaptation：直接更新模型参数。
2. Inference adaptation：调整推理过程。
3. Normalization adaptation：更新归一化统计或参数。
4. Sample adaptation：处理或选择测试样本。
5. Prompt adaptation：针对提示或上下文进行适应。

## 对本项目有用的地方

本项目可以定位在两个分类交叉处：

- Model adaptation：因为 OTTA 会通过 LoRA 更新模型。
- Sample adaptation：因为核心创新是测试样本选择。

这比泛泛说“我们做 TTA”更清楚。

## 和其他方向的关系

| 方向 | 与本项目关系 |
|---|---|
| Domain Adaptation | 通常训练时访问目标域，不是本项目重点 |
| Domain Generalization | 训练时增强泛化，测试时不更新，不是本项目重点 |
| Source-Free Adaptation | 有中间适应阶段，本项目更强调测试流中在线更新 |
| Test-Time Adaptation | 本项目主场景 |
| Continual TTA | 本项目的流式测试和误差累积分析会用到 |
