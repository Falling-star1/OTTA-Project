## 2. 模块职责

| 模块 | 输入 | 输出 | 禁止事项 |
|---|---|---|---|
| `data/stream.py` | 原始数据、seed、数量 | 固定顺序的标准样本 | 不把标签写入适应文本 |
| `models/load.py` | 模型配置 | tokenizer、模型、LoRA 参数 | 不包含实验循环 |
| `evaluation/choices.py` | 模型、题干、选项 | 预测选项与分数 | 不更新模型 |
| `adaptation/lora.py` | 无标签文本、模型 | NLL、一次 LoRA 更新 | 不读取答案 |
| `selection/*.py` | loss/梯度/优化器状态 | selected_idx、scores | 不调用 optimizer.step |
| `runner.py` | 配置、stream、selector | 完整 run artifacts | 必须先预测后适应 |
| `scripts/run_experiment.py` | CLI 参数 | 调用 runner | 不承载算法逻辑 |

## 3. 统一选择器接口

```python
class Selector:
    def select(self, sample_losses, context):
        """
        Returns:
            selected_idx: list[int]
            scores: list[float | None]
            metadata: dict
        """
```

Random、High-PPL 和 OTTA 都通过此接口接入 runner，避免为不同方法复制实验循环。

## 4. 推荐实现顺序

1. `config.py` 与 `data/stream.py`。
2. `models/load.py` 与 `evaluation/choices.py`。
3. No Adaptation runner。
4. LoRA 无标签 NLL 与 Random。
5. High-PPL。
6. OTTA v0。
7. 主实验汇总与作图。

每完成一步都先跑 32 条 smoke test，不在同一天同时实现多个新算法模块。

## 5. 第一轮测试清单

- 相同 seed 生成相同 sample_id 顺序；
- 适应文本不包含 answer；
- 基座参数冻结，只有 LoRA 参数可训练；
- Random 每次恰好返回 k 个唯一索引；
- High-PPL 返回最大 k 个 NLL；
- 块级余弦对平行/正交/反向向量返回约 1/0/-1；
- runner 在当前 batch 更新前保存预测；
- 四种方法不会共享上一轮 optimizer 状态。
