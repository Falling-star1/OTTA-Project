# OTTA v0 代码实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build one reproducible command-line experiment that compares No Adaptation, Random, High-PPL, and optimizer-aware OTTA v0 on the same unlabeled online test stream.

**Architecture:** A single stream runner owns ordering and predict-before-adapt semantics. Selection strategies share one interface; the adapter owns LoRA loss and AdamW state; the evaluator is the only component allowed to read labels. Every run writes configuration, predictions, selections, timing, memory, and a summary.

**Tech Stack:** Python, PyTorch, Transformers, PEFT, Datasets, pytest, YAML/JSONL.

## 每次任务的验证命令

```powershell
pytest -q
python -m src.scripts.run_experiment --config configs/smoke.yaml --method no_adaptation
python -m src.scripts.run_experiment --config configs/smoke.yaml --method random
python -m src.scripts.run_experiment --config configs/smoke.yaml --method high_ppl
python -m src.scripts.run_experiment --config configs/smoke.yaml --method otta_v0
```

每条命令的成功标准：退出码为 0，run 目录同时包含 `config.json`、`predictions.jsonl`、`selections.jsonl`（No Adaptation 可为空）和 `summary.json`。
